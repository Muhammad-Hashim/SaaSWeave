# Pre-build completeness checklist

- [ ] Product brief accepted.
- [ ] V1 non-goals explicit.
- [ ] Stable US/FR/NFR/BR IDs assigned.
- [ ] Run state machine accepted.
- [ ] Browser/model/storage interfaces accepted.
- [ ] SSRF/profile/credential threats documented.
- [ ] Retry and ambiguous-side-effect policy documented.
- [ ] DB source-of-truth rule accepted.
- [ ] V1 acceptance tests written before implementation completion.
- [ ] Backup/restore scope defined.
- [ ] Browser compatibility target defined.
- [ ] Research/licensing reverified before embedding third-party OSS.
