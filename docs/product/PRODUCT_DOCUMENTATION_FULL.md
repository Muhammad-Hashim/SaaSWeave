# AgentSurf — Combined documentation entry point

The canonical product documentation is the numbered file tree under `docs/product/`.

This file intentionally does **not** duplicate every document into one giant generated blob, because duplicated documentation drifts. Use:

- `DOCUMENTATION_INDEX.md` for the complete file map.
- `V1_V2_V3_SUMMARY.md` for the release summary.
- `03_Product/` for FR/NFR/business requirements.
- `09_Roadmap and decisions/` for roadmap and architectural decisions.
- `10_Agent implementation/006_V1 task breakdown.md` for the implementation backlog.
- repository root `PROGRESS.md` for current/done/next execution state.

For agent work, start at `docs/product/AGENTS.md`.
