# Master research prompt

Use this when updating research before a major version.

> Research the current browser-agent/browser-infrastructure ecosystem using primary sources first. Compare managed browser providers, self-hosted browser APIs, browser-agent SDKs and relevant open-source projects. Verify current licensing, self-hosting support, browser/CDP compatibility, session/profile behavior, agent APIs, proxy/CAPTCHA claims, deployment models and SDK languages. Separate facts from recommendations. Identify which components should be reused instead of rebuilt. Update `02_Research`, any affected decisions, and version scope. Do not change implementation requirements solely from marketing claims; require a documented decision.
