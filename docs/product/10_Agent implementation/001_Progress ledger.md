# Progress ledger

Canonical live tracker: repository root `PROGRESS.md`. This file explains the required format.

Each implementation PR must update `PROGRESS.md` with:

- current task ID and status;
- completed task IDs;
- requirement IDs satisfied;
- branch/PR/commit;
- tests and migrations;
- known limitations;
- exact next task.

Never mark a requirement complete because code merely exists. Completion requires its acceptance evidence.
