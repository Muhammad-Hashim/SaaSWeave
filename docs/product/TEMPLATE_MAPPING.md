# Template mapping

This package was produced from the structure and intent of `Muhammad-Hashim/docment-template`. The goal is not to preserve placeholder filenames mechanically; it is to fill the same documentation responsibilities with implementation-ready AgentSurf product content.

| Original template area | Filled product documentation |
|---|---|
| 00 Start here | usage, lifecycle, evidence rules |
| 01 Discovery | product brief, validation, success metrics |
| 02 Research | category, competitors, OSS, feasibility, build-vs-reuse |
| 03 Product | PRD, stories, FRs, NFRs, business rules, edge cases, version matrix |
| 04 Design and flows | use cases, state machine, sequences, screens, E2E flows |
| 05 Engineering | architecture, DB, API, jobs, storage, browser runtime, model providers, observability, recovery, events, repo structure |
| 06 Security/privacy | threat model, authorization, privacy, secrets, browser isolation |
| 07 QA | test strategy, acceptance tests, compatibility, load/reliability |
| 08 Deployment/operations | self-host, backup/restore, upgrade/rollback, production topology, configuration |
| 09 Roadmap/decisions | V1/V2/V3 roadmap, ADR-style decisions, traceability, timeline, backlog |
| 10 Agent implementation | agent contract, progress ledger, task template, research/implementation prompts, PR workflow, V1 tasks |
| 11 Checklists | pre-build, release, security, deployment, completeness |
| 12 Examples | API, Docker, tasks, webhooks, SDK |
